# Label Studio

Design and print labels on a USB DYMO LabelWriter, right from Home Assistant.

- Live preview of every label as you type.
- Fonts, text that wraps and hyphenates to fit, Material Design icons, emoji and QR codes.
- Home Assistant templates in labels, filled in when printing: dates, times, sensor values.
- Save labels as templates; each one becomes a print button in Home Assistant (via MQTT).
- All 55 label sizes of the LabelWriter 400/450 driver, with per-label print corrections.
- Optional: share the printer on your network, so computers and phones can print to it.

See the **Documentation** tab for setup and usage.
